# 📞 Agenda Telefónica

Aplicación desarrollada en Java para gestionar contactos de una agenda telefónica desde consola.

- Erick Alan González Mora

- Michael Castro Romero
- Isaac Ulises Pérez Bravo

## 🚀 Características

- Agregar contactos.
- Buscar contactos por nombre.
- Mostrar todos los contactos registrados.
- Editar información de contactos.
- Eliminar contactos.
- Validación de datos básicos.

## 🛠️ Tecnologías utilizadas

- Java
- Programación Orientada a Objetos (POO)
- Colecciones de Java (ArrayList)
